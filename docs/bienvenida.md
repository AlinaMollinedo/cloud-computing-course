# Bienvenidos al Curso

Bienvenidos a la documentación del curso de **Computación en la Nube**. Aquí encontraras los materiales, guías y referencias para seguir el curso.

---

## Objetivos del Curso

### Docker
- VMs vs Contenedores
- Arquitectura Docker
- Imágenes y capas
- Dockerfile y construcción de imágenes
- Registro de contenedores
- Docker Compose
- Redes
- Volúmenes persistentes

### Cloud (AWS)
Material en el apartado **AWS**:
- [Conceptos básicos](./aws/conceptos-basicos.md)
- [EC2](./aws/ec2.md) — cómputo
- [RDS](./aws/rds.md) — bases de datos relacionales
- [DynamoDB](./aws/dynamodb.md) — NoSQL
- [S3](./aws/s3.md) — almacenamiento
- [Lambda](./aws/lambda.md) — serverless
- [Arquitectura event-driven](./aws/arquitectura-event-driven.md) (extra)
- [Workshops](./aws/workshops/carga-csv-s3-lambda-dynamodb.md)

### CI/CD
- Conceptos CI/CD
- Pipeline stages
- Herramientas: Jenkins, GitLab CI, GitHub Actions
- Estructura de pipelines: stages, jobs, artefactos
- Testing automatizado
- Estrategias de deployment (blue-green, canary)

### Kubernetes
- Arquitectura K8s y componentes
- Conceptos básicos: Pods, Nodes
- Deployments, ReplicaSets y estrategias de actualización
- Services: ClusterIP, NodePort, LoadBalancer
- Ingress
