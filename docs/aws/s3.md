# S3: almacenamiento de objetos

**Amazon S3** (Simple Storage Service) guarda archivos (objetos) de forma duradera y barata. Aquí verás buckets, claves, permisos y un hosting estático sencillo.

---

## ¿Qué es S3?

S3 no es un disco de red como EBS. Es **almacenamiento de objetos**: cada archivo tiene una **clave** (ruta), metadatos y el contenido.

> Analogía: un bucket es un “disco en internet” ilimitado; cada objeto es un archivo con una URL (si lo publicas) o acceso privado vía IAM.

Casos de uso: backups, imágenes, logs, sitios estáticos, datasets, artefactos de CI/CD.

---

## Conceptos clave

| Concepto | Descripción |
| -------- | ----------- |
| **Bucket** | Contenedor de objetos. El nombre es **globalmente único**. |
| **Objeto** | El archivo + metadatos. Tamaño desde 0 bytes hasta 5 TB. |
| **Key** | Ruta del objeto, ej. `fotos/2026/logo.png`. |
| **Región** | El bucket vive en una región. Elige la más cercana a tus usuarios. |
| **Versioning** | Conserva versiones anteriores al sobrescribir o borrar. |
| **Clases de almacenamiento** | Standard, Infrequent Access, Glacier… según frecuencia de acceso. |
| **Block Public Access** | Por defecto los buckets **no** son públicos. |

Nombres de bucket: minúsculas, sin espacios; algo como `curso-cloud-tuusuario-2026`.

## Crear un bucket y subir un archivo (CLI)

```bash
# Crear bucket (us-east-1 no usa LocationConstraint)
aws s3 mb s3://curso-cloud-tuusuario-2026

# En otra región:
# aws s3 mb s3://curso-cloud-tuusuario-2026 --region sa-east-1

# Subir un archivo
echo "hola s3" > hola.txt
aws s3 cp hola.txt s3://curso-cloud-tuusuario-2026/hola.txt

# Listar
aws s3 ls s3://curso-cloud-tuusuario-2026

# Descargar
aws s3 cp s3://curso-cloud-tuusuario-2026/hola.txt hola-descargado.txt
```

API de “alto nivel” `aws s3` vs API precisa `aws s3api` (create-bucket, put-object, etc.).

## Permisos: privado por defecto

Un objeto **privado** solo lo leen identidades con permiso IAM (tu usuario, un rol de Lambda/EC2).

Patrones habituales:

1. **Privado + IAM:** la app lee con un rol (recomendado).
2. **URL prefirmada:** enlace temporal para un archivo concreto.
3. **Público:** solo para contenido que realmente deba ser público (sitio estático, assets).

URL prefirmada (válida 5 minutos):

```bash
aws s3 presign s3://curso-cloud-tuusuario-2026/hola.txt --expires-in 300
```

:::caution
No desactiva “Block Public Access” salvo que sepas por qué. Un bucket abierto con datos personales o claves es un incidente de seguridad clásico.
:::

## Sitio web estático (práctica)

1. Crea un `index.html`:

```html
<!DOCTYPE html>
<html>
  <head><meta charset="utf-8"><title>Mi sitio S3</title></head>
  <body><h1>Hosteado en S3</h1></body>
</html>
```

2. Sube el archivo y habilita el hosting estático desde la consola (**Bucket** → **Properties** → **Static website hosting**) o con CLI.

```bash
aws s3 cp index.html s3://curso-cloud-tuusuario-2026/index.html \
  --content-type text/html
```

En producción actual se suele poner **CloudFront** delante (HTTPS, caché, dominio). Para el curso, entender el bucket y los objetos es suficiente.

## S3 vs EBS vs EFS

| Servicio | Tipo | Se monta en EC2 | Uso típico |
| -------- | ---- | --------------- | ---------- |
| **S3** | Objetos (HTTP/API) | No como disco | Archivos, backups, estáticos |
| **EBS** | Bloque | Sí (un volumen ≈ un disco) | Disco de la instancia |
| **EFS** | NFS | Sí, varias instancias a la vez | Compartir archivos entre EC2 |

---

## Ciclo de vida y costes

- Almacenamiento: pagas por GB/mes.
- Requests: PUT/GET tienen un coste pequeño.
- Transferencia de **salida** a internet se cobra; entrada suele ser gratis.

Reglas de **lifecycle**: pasar objetos viejos a Glacier o expirarlos (útil para logs).

---

## Reto del día

1. Crea un bucket con un nombre único.
2. Sube `index.html` y `hola.txt`.
3. Genera una URL prefirmada de `hola.txt` y ábrela en el navegador.
4. Lista el bucket con `aws s3 ls` y haz una captura.
5. Vacía y elimina el bucket si ya no lo necesitas:

```bash
aws s3 rm s3://curso-cloud-tuusuario-2026 --recursive
aws s3 rb s3://curso-cloud-tuusuario-2026
```
